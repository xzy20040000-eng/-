# 销售图片工作台（测试版）

手机和电脑共用的销售图片制作网页。销售登录后，只能看到和修改自己创建的记录。

## 当前流程

1. 点击“创建图片”，从 5 位讲师的 5 张正式培训海报中选择模板。
2. 填写时间、地址，上传律所 Logo；二维码可稍后上传。
3. 根据律所 Logo 主色直接替换指定设计区域的颜色，生成 2484 × 5150 高清 JPG，并保存到云端记录。
4. 在“图片记录”中重新打开，修改内容或补充二维码，重新生成并覆盖同一条记录。
5. 生成成功提示中可导出 JPG、继续修改或关闭。

用户记录保存在 D1，原始 Logo、二维码和生成的 JPG 保存在 R2。高清图片先作为原始二进制上传，再提交少量表单信息，避免表单体积限制降低画质。销售使用手机号和密码自行注册、登录，接口按账号 ID 校验记录归属。手机号只用作账号名，不进行短信验证。

## 模板处理

原始 PSD 用于提取五张海报的独立色块、文字和人物边缘范围，不调用 Photoshop。五张 PDF 以 144 DPI 渲染为网页底图，再将完整画面适配到 1242 × 2575，保留底部标语条。生成时在 PSD 对应的设计区域内直接替换原色像素，不叠加调色蒙版。律所 Logo 与原色智合AI Logo 根据实际可见范围等比缩放、左右对齐，避免重叠或遮挡标题。五张海报共用一套底部信息排版：月日大字、斜杠、星期及时间，地址分行，圆角二维码框，下面是“扫码进群，免费报名”和“领取 10 天免费试用”。地址断句保留输入的全部文字；销售自行截图框选二维码后上传，未上传时框内显示“待上传”。导出 JPG 品质为 98%。打印前须核对地址和二维码扫码效果。

当前没有密码找回流程，忘记密码需要管理员协助处理。

## 开发

项目使用 Vinext/React、D1 和 R2。运行环境按 Sites 插件流程安装依赖、生成迁移、构建和部署。数据库迁移位于 `drizzle/`。
